# Multi-agent specialization

Specialists can improve coverage when tasks require different evidence and tools. They can also increase cost, duplicate work, create inconsistent assumptions, and generate more unsupported claims. A useful specialist emits a typed contribution into shared state rather than an isolated essay.

The credit, macro/rates, relative-value, and evidence roles in this project share one evidence namespace and one audit trail. The capstone holds cases constant and measures whether specialization changes completion, support, risk recall, and steps. Role labels alone receive no quality credit.
