# Memory and research state

Useful memory is selective, typed, and governed. An analyst needs current-case evidence and unresolved questions, prior hypotheses with dates, and stable methodology—not an undifferentiated transcript. Persistent memory also introduces staleness, confidentiality, data-retention, and cross-issuer contamination risks.

The prototype demonstrates persistent structured state within one run. Cross-run memory is intentionally absent. Adding it should require versioned evidence, expiry rules, issuer isolation, correction semantics, and experiments showing an improvement over re-retrieval.
